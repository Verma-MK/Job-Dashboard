# Job Dashboard

## 📌 Overview
The **Job Dashboard** is an interactive data visualization project built to analyze job market trends, salary insights, and demand across different roles in the data domain. It provides meaningful insights into job distribution, salary comparisons, and hiring trends.

---

## 🚀 Features

- 📈 **Job Trend Analysis**  
  Visualizes monthly job posting trends to identify hiring patterns.

- 💰 **Salary Insights**  
  Displays:
  - Median yearly salary
  - Median hourly salary

- ⭐ **Job Ratings Overview**  
  Shows overall job satisfaction using star ratings.

- 📊 **Yearly vs Hourly Salary Comparison**  
  Scatter plot comparing salary structures across different job roles.

- 🏆 **Highest Paying Jobs**  
  Highlights top-paying roles like:
  - Machine Learning Engineer  
  - Senior Data Scientist  
  - Data Engineer  

- 🔍 **Interactive Filters**  
  Filter data by job title for focused analysis.

- 📋 **Detailed Job Table**  
  Includes:
  - Job count  
  - Hourly salary  
  - Yearly salary  
  - Job trend  

---

## 🛠️ Tools & Technologies

- **Power BI** – Data visualization & dashboard creation  
- **Excel / CSV** – Data source  
- **Data Cleaning & Transformation** – Power Query
